## Git Workflow Used

1. Team Leader created the repository and added collaborators.
2. Each member cloned the repository.
3. Each member created a feature branch (`feature/home`, `feature/about`, `feature/services`, `feature/contact`).
4. Work was committed and pushed to the feature branch.
5. A Pull Request was opened for each branch and reviewed by the Team Leader.
6. Approved Pull Requests were merged into `main`.
7. Members ran `git switch main` and `git pull origin main` to update locally.
8. A merge conflict was created and resolved as additional practice.
