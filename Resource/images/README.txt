PHOTOS FOLDER  (Resource/images)
================================
Put the website photos here. File names must match EXACTLY (small letters, no spaces).

  logo.png          University logo. Used on the loading screen, top bar, menu, footer.
                    (square picture, transparent background looks best)
  hero.jpg          Big photo at the top of the Home page (and the banners of other pages).
  about.jpg         Photo on the About page.

  news/             Photos for NEWS.           (see news/README.txt)
  announcement/     Photos for ANNOUNCEMENTS.  (see announcement/README.txt)

If a photo is missing the site does NOT break: a coloured box is shown instead.
Tip: keep each photo under about 500 KB so the page loads fast.
(These README files also make git keep the empty folders.)
